# Prompt Engineering Library

A structured collection of high-quality prompts for modern AI-powered workflows across development, design, and productivity.

## Why This Exists

Prompt engineering is a practical skill that improves output quality, consistency, and speed when working with AI tools. This repository exists to organize reusable prompts by domain so individuals and teams can quickly find, adapt, and apply the right prompt for the task.

## Categories

- **web-development**: Next.js, React, and Tailwind prompts
- **ui-ux-design**: Lovable.dev, V0, and Framer Motion prompts
- **ai-engineering**: LLM orchestration, RAG systems, and Python scripts
- **productivity**: General workflow and execution prompts

## Contribution Guidelines

Contributions are welcome. To keep this library useful and consistent:

1. Add prompts to the most relevant category folder.
2. Use clear titles and include context, intent, and expected output format.
3. Keep prompts practical, concise, and easy to adapt.
4. Update category README files when introducing new subtopics.
5. Open a pull request with a short explanation of what you added and why.

## 🚀 Overview

The **Prompts Library** is a curated, battle-tested collection of production-grade AI prompts engineered to maximize the output quality of leading LLMs — **Claude**, **GPT-4**, **Gemini** — and AI-assisted dev tools like **Lovable** and **v0**.

> Every prompt in this library is designed with *precision*, *repeatability*, and *real-world deployment* in mind. Not just demos — production assets.

```
📦 Prompts Library
 ┣ 🤖 AI Engineering      — RAG, LLM orchestration, fine-tuning
 ┣ 🎨 UI/UX Design        — Lovable.dev, Framer Motion, design systems
 ┣ 👨‍💻 Web Development     — Next.js, Tailwind, clean architecture
 ┗ 🧩 Workflow Automation  — Agents, pipelines, multi-step reasoning
```

## ⚡ Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/Gohar-Hany/Prompts-Library.git
cd Prompts-Library
```

### 2. Browse Categories

```bash
ls -la  # Explore folders
```

### 3. Use a Prompt

```
1. 📂 Open any category folder
2. 📋 Copy the prompt content
3. ✏️  Replace all [PLACEHOLDER] values with your context
4. 🚀 Paste into Claude / GPT-4 / Gemini
5. ✅ Get production-quality output
```

### 4. Prompt Anatomy

Every prompt follows this structure:

```
╔══════════════════════════════════════╗
║  ROLE          → Who the AI is       ║
║  CONTEXT       → What it knows       ║
║  TASK          → What to do          ║
║  CONSTRAINTS   → Rules & limits      ║
║  FORMAT        → Output structure    ║
╚══════════════════════════════════════╝
```

## 🤝 Contributing

Contributions make this library more powerful. Here's how:

```bash
# Fork → Clone → Create branch
git checkout -b feat/your-prompt-category

# Add your prompt(s)
# Follow the naming convention: category/use-case/prompt-name.md

# Commit with context
git commit -m "feat(ai-engineering): add RAG evaluation prompt"

# Push & open a PR
git push origin feat/your-prompt-category
```

**Prompt submission checklist:**
- [ ] Follows the Role → Context → Task → Constraints → Format structure
- [ ] Tested on at least one major LLM (Claude, GPT-4, or Gemini)
- [ ] Includes a sample output or expected result
- [ ] All `[PLACEHOLDERS]` are clearly labeled
- [ ] Category folder is appropriate
